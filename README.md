# Hearth docs

The documentation site for Hearth, a hosting market for app chains: hire anyone to host your app's chain, pay by the day, and check every read in your browser or on your own node. It is plain Markdown that GitHub Pages builds with its default Jekyll and the `jekyll-theme-primer` theme. The code it documents is at [github.com/hearthnet/hearth](https://github.com/hearthnet/hearth).

## Preview locally

If you have Jekyll and the theme installed (`gem install jekyll jekyll-theme-primer jekyll-relative-links`):

```
jekyll serve
```

Then open http://127.0.0.1:4000/.
